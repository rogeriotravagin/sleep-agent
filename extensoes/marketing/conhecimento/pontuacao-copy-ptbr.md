# Guia de Pontuação para Copy - Português Brasileiro

## A pontuação é a respiração do texto.

Errar a pontuação numa copy é como cantar na nota errada. O leitor sente. Não sabe explicar o que está errado, mas sente. E vai embora.

Este guia cobre **cada sinal de pontuação** com regras claras, exemplos práticos e a lógica por trás do uso em textos persuasivos.

---

## 1. PONTO FINAL (.)

### O que faz
Encerra uma ideia. Cria uma pausa completa. Força o leitor a parar e processar.

### Quando usar
- Pra fechar uma declaração afirmativa
- Pra criar impacto com frase curta
- Em comandos diretos
- Pra encerrar um bloco de argumento

### Quando NÃO usar
- **Em títulos, subtítulos e headlines (SEMPRE).** Títulos só podem ter `!`, `?` ou nada.
- Em sequência excessiva (texto metralhadora)
- Quando uma vírgula manteria melhor o fluxo
- **Em fragmentos artificiais de impacto** (ex: "evoluiu. Muito." = ERRADO, "evoluiu muito" = CORRETO)

### A armadilha do excesso
Muitos pontos finais seguidos = texto picado, sem ritmo, cansativo.

**Ruim:**
```
O método funciona. Ele é comprovado. Mais de mil pessoas usaram. Os resultados são rápidos. Você pode começar hoje.
```

**Bom:**
```
O método funciona, e é comprovado por mais de mil pessoas.

Os resultados são rápidos. Quer começar hoje? Pode.
```

### Técnica avançada: Ponto como martelo
Frase curta + ponto = impacto máximo. Mas só funciona quando há contraste com frases mais longas ao redor.

```
Eu tentei de tudo. Li livros, fiz cursos, contratei mentor, investiu R$ 40 mil em treinamentos ao longo de dois anos.

Nada funcionou.

Até que mudei UMA coisa.
```

O "Nada funcionou." ganha peso justamente porque vem depois de uma frase longa.

## 2. VÍRGULA (,)

### O que faz
Cria uma pausa breve. Mantém o fluxo da leitura. Conecta ideias dentro de uma mesma frase.

### Regras que importam pra copy

**a) Antes de "mas", "porém", "contudo", "entretanto"**
```
✅ Você trabalha muito, mas não vê resultado.
❌ Você trabalha muito mas não vê resultado.
```

**b) Depois de advérbios no início da frase**
```
✅ Hoje, você vai aprender algo novo.
✅ Infelizmente, a maioria desiste cedo.
```
(Em copy informal, essa vírgula pode ser omitida quando a frase é curta: "Hoje você vai aprender algo novo.")

**c) Para isolar explicações (aposto)**
```
✅ O Pedro, dono da empresa, faturou R$ 1 milhão.
✅ Esse método, criado em 2019, já ajudou 5 mil pessoas.
```

**d) Separar itens de uma série**
```
✅ Você precisa de foco, disciplina e estratégia.
✅ Foco, disciplina, estratégia: os três pilares.
```

**e) NUNCA entre sujeito e verbo**
```
❌ O método, funciona.
✅ O método funciona.

❌ Quem aplica esse sistema, vende mais.
✅ Quem aplica esse sistema vende mais.
```
Esse é o erro mais grave. Vírgula entre sujeito e verbo é um crime gramatical que nenhum nível de informalidade justifica.

### Vírgula opcional em copy
Em textos curtos e informais, a vírgula pode ser omitida quando não gera ambiguidade:
```
Formal: Ontem, eu descobri um método.
Informal: Ontem eu descobri um método.
```
Ambas corretas. A segunda flui melhor em copy conversacional.

### A vírgula como respiração
Leia o texto em voz alta. Onde você naturalmente faz uma pausa curta? Ali vai a vírgula.

```
Se você está cansado de tentar e não conseguir, eu tenho uma boa notícia.
```

## 3. RETICÊNCIAS (...)

### O que faz
Cria suspense. Sugere continuidade. Deixa uma ideia no ar. Convida o leitor a completar o pensamento.

### Quando usar em copy
- Pra criar curiosidade
- Pra sugerir que tem mais
- Pra simular pensamento em andamento
- Pra criar pausa dramática
- Como transição emocional

### Exemplos de uso correto

**Curiosidade:**
```
Existe um método que poucos conhecem...

E ele muda tudo.
```

**Suspense:**
```
Eu estava prestes a desistir...

Quando recebi aquela mensagem.
```

**Reflexão:**
```
Pensa comigo...

Quanto tempo você já perdeu fazendo o que não funciona?
```

**Transição suave:**
```
Você trabalha, se dedica, dá o seu melhor...

Mas o resultado não vem.
```

### Regras técnicas
- São TRÊS pontos. Não dois (..), não quatro (....).
- Não coloque espaço antes das reticências: "errado ..." → "certo..."
- Depois das reticências, pode começar com maiúscula ou minúscula (depende se é frase nova ou continuação)
- Frase nova após reticências: maiúscula
  ```
  Eu tentei de tudo... Nada funcionou.
  ```
- Continuação: minúscula
  ```
  Eu tentei de tudo... mas nada funcionou.
  ```

### A armadilha do excesso
Reticências demais = texto preguiçoso, vago, sem direção.

**Ruim:**
```
Então... eu pensei... será que funciona... e resolvi testar... e olha... funcionou...
```

**Bom:**
```
Eu pensei: será que funciona?

Resolvi testar.

Funcionou.
```

### Regra prática
Máximo de 2-3 usos de reticências por seção/email. Use pra momentos de real suspense ou reflexão, não como muleta.

## 4. TRAVESSÃO (—) - PROIBIDO

### DIRETRIZ: NÃO USAR

O travessão (—) é **PROIBIDO** em todos os materiais do Sleep Agent. Sem exceção.

### O que é
O travessão (—) é diferente do hífen (-) e da meia-risca (–):
- **Hífen (-)**: une palavras compostas (bem-vindo, guarda-chuva) - PERMITIDO
- **Meia-risca (–)**: intervalos (10–20) - EVITAR
- **Travessão (—)**: pontuação de ênfase - **PROIBIDO**

### Como substituir

Onde antes usaria travessão, use vírgula, ponto, dois-pontos ou reestruture a frase:

```
❌ Esse método — que leva menos de 30 minutos — mudou minha vida.
✅ Esse método, que leva menos de 30 minutos, mudou minha vida.

❌ A resposta é simples — você está fazendo errado.
✅ A resposta é simples: você está fazendo errado.

❌ Todo mundo quer resultados rápidos — mas ninguém quer fazer o trabalho.
✅ Todo mundo quer resultados rápidos, mas ninguém quer fazer o trabalho.

❌ Só precisa de uma coisa — coragem.
✅ Só precisa de uma coisa: coragem.
```

### Motivo
Preferência consolidada. Travessões quebram o fluxo de leitura e não fazem parte do padrão de copy adotado.

## 5. PONTO DE EXCLAMAÇÃO (!)

### O que faz
Expressa emoção forte: entusiasmo, surpresa, urgência, raiva.

### A regra de ouro
**Máximo 1 por parágrafo. De preferência, 1 a cada 3-4 parágrafos.**

Exclamação é tempero forte. Pouco realça. Muito estraga.

### Quando usar
- CTA final de uma seção
- Reação genuína de surpresa
- Entusiasmo sobre resultado
- Urgência real

### Quando NÃO usar
- Em série (!!!)
- Em cada frase
- Quando o conteúdo já transmite emoção
- Pra compensar texto fraco

### Exemplos

**Bom, uso moderado:**
```
Você vai se surpreender com a simplicidade.

Sério. É tão simples que dá raiva de não ter descoberto antes!

E o melhor: funciona pra qualquer pessoa.
```

**Ruim, exclamação como muleta:**
```
Isso é incrível! Você vai amar! Os resultados são surpreendentes! Não perca essa oportunidade! Clique agora!
```

### Teste rápido
Se você tirar a exclamação e a frase perder todo o peso, a frase é fraca. O problema não é a pontuação, é o conteúdo.

```
Fraco: "Nosso produto é bom!"
Forte: "Nosso produto cortou o tempo de trabalho pela metade."
(Não precisa de exclamação porque o fato fala por si.)
```

## 6. PONTO DE INTERROGAÇÃO (?)

### O que faz
Transforma declaração em diálogo. Engaja o leitor. Força reflexão.

### Por que é poderoso em copy
Pergunta ativa o cérebro. O leitor é obrigado a pensar numa resposta. E enquanto pensa, está engajado.

### Tipos de pergunta em copy

**Pergunta retórica (a mais poderosa):**
```
Sabe o que separa quem fatura de quem reclama?
```
(O leitor pensa "o quê?" e continua lendo.)

**Pergunta de dor:**
```
Cansado de trabalhar 12 horas por dia e não ver resultado?
```
(O leitor pensa "SIM" e se identifica.)

**Pergunta de possibilidade:**
```
E se você pudesse dobrar sua renda em 90 dias?
```
(O leitor pensa "seria incrível" e quer saber como.)

**Pergunta de desafio:**
```
Você vai continuar fazendo a mesma coisa e esperando resultado diferente?
```
(O leitor se sente provocado.)

### Sequência pergunta + resposta
Uma das técnicas mais poderosas em copy:

```
Qual é o segredo?

Método.

Não talento. Não sorte. Não dinheiro.

Método.
```

### Cuidado com excesso
Muitas perguntas seguidas = interrogatório. O leitor se irrita.

**Ruim:**
```
Você quer vender mais? Quer ter mais tempo livre? Quer parar de se preocupar com dinheiro? Quer viver a vida que sempre sonhou?
```

**Bom:**
```
Você quer vender mais, ter mais tempo e parar de se preocupar com dinheiro?

Então lê o que vem a seguir.
```

## 7. DOIS-PONTOS (:)

### O que faz
Anuncia o que vem. Cria expectativa. Funciona como "olha isso aqui:"

### Quando usar em copy

**Antes de revelação:**
```
O problema é um só: você está no mercado errado.
```

**Antes de lista:**
```
Três coisas que você precisa:

1. Um método
2. Consistência
3. Paciência
```

**Depois de "pergunta":**
```
A grande questão: quanto você está disposto a investir em você?
```

### Técnica: dois-pontos como anzol
```
Vou te contar o que fez a diferença:
```
(O leitor não consegue parar aqui. Precisa ler o que vem depois.)

### Regra
Depois de dois-pontos: minúscula (se continua a frase) ou maiúscula (se é frase nova/lista).
```
O segredo é simples: dedicação.
O segredo é simples: Você precisa se dedicar todos os dias.
```

## 8. PONTO E VÍRGULA (;)

### Em copy: quase nunca use.

O ponto e vírgula é elegante em literatura. Em copy, é distante.

### Quando poderia usar
- Separar itens complexos de uma lista que já usa vírgulas internamente
- Conectar duas frases intimamente relacionadas sem começar parágrafo novo

### Na prática
Substitua por ponto final ou dois-pontos. O leitor agradece.

```
❌ Nosso método é rápido; você vê resultado em 30 dias.
✅ Nosso método é rápido. Em 30 dias, você vê resultado.
✅ Nosso método é rápido: resultado em 30 dias.
```

## 9. ASPAS (" ")

### No português brasileiro
Usamos **aspas duplas** como padrão. Aspas simples só dentro de aspas duplas.

### Quando usar em copy

**Citação direta (depoimento):**
```
"Faturei R$ 47 mil no primeiro mês." - João, São Paulo
```

**Destacar termo irônico ou questionável:**
```
Eles chamam de "estratégia avançada". Eu chamo de perda de tempo.
```

**Referência a algo dito:**
```
Todo mundo fala "vou mudar de vida". Poucos fazem.
```

### Cuidado
Não use aspas pra ênfase. Pra isso, use **negrito** ou MAIÚSCULAS.

```
❌ Nosso produto é "incrível".
(Parece irônico, como se NÃO fosse incrível.)

✅ Nosso produto é incrível.
✅ Nosso produto é INCRÍVEL.
```

## 10. PARÊNTESES ( )

### O que faz
Insere informação complementar. Cria tom de "entre nós", de confidência.

### Quando usar em copy

**Comentário íntimo:**
```
Consegui R$ 10 mil no primeiro mês (e olha que eu comecei do zero).
```

**Dado complementar:**
```
Nosso método funciona rápido (média de 30 dias pra primeiro resultado).
```

**Tom sarcástico ou irônico:**
```
O guru prometeu liberdade financeira (vendendo curso de R$ 4.997).
```

### Em copy informal
Parênteses funcionam bem pra criar sensação de conversa. Como se você estivesse sussurrando um comentário pro leitor.

```
Vou te mostrar o método (mas presta atenção, porque é mais simples do que parece).
```

### Cuidado
Não aninhê parênteses dentro de parênteses. E não coloque frases longas demais entre parênteses, reestruture a frase.

## QUADRO DE FREQUÊNCIA RECOMENDADA

| Sinal | Frequência em Copy | Função Principal |
|-------|-------------------|------------------|
| . | Moderado (variar com outros) | Encerrar, impactar |
| , | Liberal (onde natural) | Fluir, conectar |
| ... | 2-3x por seção | Suspense, reflexão |
| — | **PROIBIDO** | Substituir por vírgula, ponto ou dois-pontos |
| ! | 1x a cada 3-4 parágrafos | Emoção genuína |
| ? | 1-2x por seção | Engajar, provocar |
| : | Quando anunciar algo | Revelar, listar |
| ; | Quase nunca | Conectar (prefira ponto) |
| " " | Depoimentos e ironia | Citar, destacar |
| ( ) | Quando couber | Comentário íntimo |

## PADRÕES DE PONTUAÇÃO EMOCIONAL

### Padrão 1: Pergunta → Pausa → Resposta curta
```
Sabe qual é o problema?

Você.
```

### Padrão 2: Reticências → Revelação
```
Eu descobri algo...

Algo que muda tudo.
```

### Padrão 3: Afirmação → Dois-pontos → Impacto
```
A verdade é uma só: você tá sendo enganado.
```

### Padrão 4: Lista rítmica → Ponto final seco
```
Trabalha.
Estuda.
Se dedica.
Repete.

E nada muda.
```

### Padrão 5: Frase longa → Fragmento
```
Depois de anos tentando tudo, investindo tempo e dinheiro em coisas que não funcionavam, ouvindo conselho de gente que nunca fez nada na vida...

Eu parei.
```

## TESTE DE PONTUAÇÃO

Antes de publicar, responda:

1. [ ] Usei pelo menos 3 sinais de pontuação diferentes?
2. [ ] Não tenho mais de 4 pontos finais seguidos sem variação?
3. [ ] Tenho pelo menos 1 pergunta retórica?
4. [ ] Usei reticências pra suspense (não como muleta)?
5. [ ] Não abusei de exclamação (máx 1 por parágrafo)?
6. [ ] NÃO usa travessão (—) em nenhum momento? (PROIBIDO)
7. [ ] As vírgulas estão onde eu faria pausa natural ao falar?
8. [ ] Não separei sujeito de verbo com vírgula?
9. [ ] A pontuação cria ritmo variado quando leio em voz alta?

10. [ ] Títulos e subtítulos NÃO têm ponto final, dois-pontos ou reticências?
11. [ ] Títulos e subtítulos só usam `!`, `?` ou nenhuma pontuação final?

Se todas as respostas forem sim, a pontuação está boa.
